# Kaervax OS — Governance & Audit

## Why

Rapid expansion increases the chance of inconsistent prices, listings, permissions, claims and operational decisions. Governance keeps speed from becoming uncontrolled change.

## Audit events

Record when practical:
- who/what initiated the action
- object affected
- action
- timestamp
- previous state reference
- new state reference
- result
- error reference

## Change classes

### Low risk
Content metadata, internal notes, task status.

### Medium risk
Listings, campaign configuration, partner activation.

### High risk
Pricing, financial terms, credential/access changes, destructive bulk operations.

High-risk changes should require explicit confirmation or a controlled approval workflow.
