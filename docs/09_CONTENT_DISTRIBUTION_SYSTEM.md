# Kaervax OS — Content Distribution System

## Content pipeline

```
Idea → Brief → Production → QA → Publish → Measure → Repurpose/Iterate
```

## Content types

- product education
- demonstration
- proof/evidence
- FAQ
- comparison/context
- creator content
- promotional content
- marketplace listing assets

## Asset metadata

- asset_id
- product/SKU
- channel eligibility
- format
- owner
- status
- source
- publish date
- campaign
- performance reference

## Rules

1. One canonical product fact base.
2. Adapt format per channel.
3. Avoid unsupported claims.
4. Keep commercial claims traceable.
5. Reuse proven assets where appropriate.
6. Measure downstream outcomes, not only content metrics.
