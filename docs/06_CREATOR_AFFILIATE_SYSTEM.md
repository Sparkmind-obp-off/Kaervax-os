# Kaervax OS — Creator & Affiliate System

## Objective

Create a repeatable creator/affiliate channel without making the internal system dependent on one platform.

## Entities

- creator
- affiliate relationship
- campaign
- content asset
- attribution reference
- conversion
- commission record
- payout status

## Lifecycle

```
Prospect → Invited → Approved → Activated → Producing → Converting → Reviewed
```

## Creator onboarding

- profile
- audience/context
- product fit
- approved claims
- content guidelines
- tracking/attribution
- commission terms
- support contact
- status

## Content governance

Creators should receive clear:
- product facts
- prohibited claims
- visual assets where permitted
- disclosure requirements
- brand usage guidance
- escalation path

## Measurement

Track separately:
- reach
- engagement
- clicks
- leads
- orders
- revenue
- refunds/cancellations
- attributable contribution
- operational effort

Never treat raw views as proof of commercial success.
