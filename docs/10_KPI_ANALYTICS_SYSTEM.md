# Kaervax OS — KPI & Analytics System

## Measurement layers

### Layer 1 — Activity
- listings published
- content published
- creators activated
- outreach completed

### Layer 2 — Demand
- views
- clicks
- inquiries
- saves/add-to-cart where available

### Layer 3 — Commerce
- orders
- gross sales
- refunds/cancellations
- conversion indicators

### Layer 4 — Economics
- product cost
- channel fees
- commission
- fulfillment cost
- contribution reference

### Layer 5 — Operations
- fulfillment exceptions
- response time
- partner activity
- stock incidents

## Decision loop

```
Metric → Context → Hypothesis → Action → Result → Decision
```

Dashboards should support decisions rather than become a reporting project.

## Data quality

Every metric should identify:
- source
- timestamp
- definition
- aggregation period
- known limitations
